# Implementando sua Primeira Stack com AWS CloudFormation 🚀

Este repositório contém os arquivos do desafio do curso **Implementando sua Primeira Stack com AWS CloudFormation**, do Bootcamp Code Girls.

## 📌 Objetivo
Praticar **Infraestrutura como Código (IaC)** utilizando o **AWS CloudFormation** para provisionar recursos na AWS.

## 🛠️ Arquivos
- `firewall.yaml` → Cria Security Group com acesso HTTP (porta 80).
- `ec2.yaml` → Cria instância EC2 t2.micro.
- `apache.yaml` → Configura Apache automaticamente via UserData.

## 🚀 Tecnologias
- AWS CloudFormation  
- AWS EC2  
- AWS Security Groups  
- Apache HTTP Server
